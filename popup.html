Çeviri API'si

⚠️ Henüz bir çeviri API'si eklemediniz. Çeviri çalışmayacak.
JSON formatı nasıl olmalı?
{ "url": "https://.../translate", "method": "POST", "headers": { "Authorization": "Bearer xxx" }, "bodyTemplate": "{\"q\":\"{{text}}\",\"target\":\"{{targetLang}}\"}", "responsePath": "data.translations.0.translatedText" }
{{text}} ve {{targetLang}} yer tutucuları URL veya bodyTemplate içinde otomatik değiştirilir. GET istekleri için headers ve bodyTemplate'i boş bırakabilirsiniz. Hazır örnekler (DeepL, LibreTranslate, Google Cloud Translate, MyMemory) için projenin README dosyasına bakın.
